OVERVIEW
EmbersStorm - Free Piper M350 Plane is a low poly stylized propeller aircraft ready to drop into any Unity project for free. Clean topology, atlas-ready texture, and separated parts make it easy to animate and script right away.
A great starting point for flight games, airport scenes, or any project that needs a civilian aircraft without the heavy polygon cost.

HOW TO USE

Import the package into your Unity 6 URP project
Drag the full assembled prefab into your scene
Use the separated parts (body, fan, wheels) to add rotation animations on the propeller and wheels independently
Attach your flight controller script to the root and fly


ADDITIONAL COMPATIBILITY
Designed and tested in Unity 6 with URP. Compatible with Unity 2021/2022 LTS URP with minor material reassignment. HDRP and Built-in Pipeline users will need to reassign materials — meshes are pipeline independent.
